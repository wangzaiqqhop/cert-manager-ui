多证书查询功能 — 三种实现方案

管理员灵活按需查询，选择证书类型组合，一键下载加水印文件

A

独立页面（推荐）

新增 /certificates/multi-query 路由，完整页面布局

Pros

  • 空间充裕，筛选条件、结果展示、下载操作分区清晰
  • 不需要弹窗滚动，适合结果多的情况
  • 可扩展性强，后续加功能不拥挤

Cons

  • 多一个菜单项和路由
  • 需要离开证书列表页
B

大弹窗模式

在证书列表页点击按钮，打开全屏 Dialog

Pros

  • 不需要新路由，实现快
  • 和证书列表页联动方便

Cons

  • 结果多时弹窗内滚动体验差
  • 筛选+结果+下载全挤在一个弹窗里
  • 后续加功能空间受限
C

Dashboard 小组件

在首页仪表板增加一个查询卡片

Pros

  • 入口方便，打开首页就能用

Cons

  • Dashboard 已经比较满（统计卡片+过期列表+类型分布）
  • 空间太小，结果展示受限
  • 功能混杂，仪表板职责不清
